# Atlas

Atlas is a calm personal operating system that helps one user decide where
attention belongs.

## Development

Atlas requires Node.js 20.9 or newer.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The production command runs the minimal standalone Next.js server generated by
the build. See [the deployment guide](docs/deployment.md) for Railway setup,
environment variables, verification, and the current persistence limitations.
