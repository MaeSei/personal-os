# Atlas

Atlas is a calm personal operating system that helps one user decide where
attention belongs.

## Development

Atlas requires Node.js 20.19 or newer and PostgreSQL.

```bash
npm ci
cp .env.example .env
npm run db:migrate:dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start:migrate
```

The production command applies committed migrations and runs the standalone
Next.js server generated by the build. See the [deployment guide](docs/deployment.md)
for Railway setup and [database guide](docs/database.md) for persistence details.
